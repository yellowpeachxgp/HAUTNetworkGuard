- GitHub 检查：没有 CI 状态，不能据此判定通过。

在本地 Lua 5.3.6 执行真实 `api.lua`，注入包含小数流量/时长的 CSV 响应，修复前复现：

```text
api.lua:276: bad argument #6 to 'format' (number has no integer representation)
```

已应用 PR 的 API/主循环修复，保留本地已有协议解析与用户提示改动。额外将时长在拆分前取整，避免 `59.8` 秒被显示为 `60` 秒余数；UCI 间隔取整，避免同类日志崩溃；LF 规则覆盖无扩展名的 init/config 文件。

新增 `tests/test_openwrt_runtime.lua`，实际执行请求和一轮守护循环，只替换 curl/UCI/文件等 I/O 边界；协议层拒绝小数 CSV，主循环仍额外回放浮点指标以验证 PR #3 的 `%.0f` 防御；同时覆盖登录、注销、带空格 JSON、离线和连接失败。Lua 5.1.5、5.3.6 均通过。
