# HAUTNetworkGuard 三端真实设备验收矩阵

本表用于 M6 现场验收。每个平台至少记录一台设备；所有结果必须绑定实际提交、版本、资产哈希、设备和网络环境。不得在表格、截图或日志中记录密码、完整编码字段或完整账号。

## 记录头

| 字段 | 内容 |
|---|---|
| 验收日期/操作者 |  |
| 测试提交与版本 | commit：；VERSION： |
| 资产与哈希 | Windows ZIP：；macOS DMG：；OpenWrt 清单： |
| 设备/系统 | Windows：；macOS：；OpenWrt 型号与固件： |
| 网络环境 | 校园网 SSID/接口类型（不填密码）： |
| 日志位置 | 仅填写路径或脱敏导出文件名： |

状态只使用 `通过`、`失败`、`阻塞（说明原因）`。失败或阻塞必须附命令输出、截图或日志片段位置；证据中出现密码或完整账号时应先删除并重新导出。

## 7 天稳定性记录

每天至少记录一次：设备仍在线、进程/服务数量、成功/失败/退避次数、日志文件大小、最近检测时间和是否发生崩溃。七天结束后附最终日志大小与哈希；日志只允许包含掩码账号和长度摘要。

## 完成门禁

只有 Windows、macOS、OpenWrt 三列的 A1-A13 和七天记录均为 `通过`，并且提交、资产哈希、日志位置可复核，才可以在工程台账中将 M6 标为完成。任何缺少真实请求、设备状态或安装后运行证据的项目都保持为待验证。
